# Parivar Rakshak — Life Discipline & Family Resilience System

Educational family resilience tool: score, habits, what-if scenarios, advisor mode.

## Live app (GitHub Pages)

After enabling Pages, the site will be at:

`https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

## Local open

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Google Sheet leads

See [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md).  
Set `sheetsWebhook` in `PARIVAR_DEPLOY_CONFIG` inside `index.html`.
